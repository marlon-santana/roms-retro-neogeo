# roms-retro-neogeo

6 romsets de Neo Geo (MVS) validados por CRC contra o DAT oficial do
[FinalBurn Neo](https://github.com/libretro/FBNeo) (`FinalBurn Neo (ClrMame Pro XML, Neogeo only).dat`).
Catálogo do app [RetroPocket](https://github.com/marlon-santana) — core libretro `fbneo`.

Cada `.zip` é um romset **non-merged/standalone**: já inclui, além dos chips exclusivos do jogo, um
conjunto completo de variantes da BIOS do sistema (regiões + Universe BIOS), então roda sozinho, sem
precisar de nenhum `neogeo.zip` externo ao lado.

| Set | Título |
|---|---|
| `doubledr.zip` | Double Dragon (Neo-Geo) |
| `mslug.zip` | Metal Slug - Super Vehicle-001 |
| `mslug3.zip` | Metal Slug 3 (NGM-2560) |
| `samsho2.zip` | Samurai Shodown II / Shin Samurai Spirits |
| `sonicwi2.zip` | Aero Fighters 2 / Sonic Wings 2 |
| `whp.zip` | World Heroes Perfect |

Excluídos da pasta de origem por não serem Neo Geo (MVS): `mshvsf.zip` (CPS2, Capcom),
`ssridersebc.zip` (hardware Konami/TMNT), um `.zip` de Neo Geo **Pocket** (portátil, plataforma
diferente) e 3 downloads incompletos (`.crdownload`).
